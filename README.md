## Как запустить

```bash
npm install       # только TypeScript, больше ничего
npm run build     # tsc -p .  → dist/
npm start         # локальный сервер http://127.0.0.1:5173
```

Откройте `http://127.0.0.1:5173` и нажмите **Играть**.

> Игра использует ES-модули, поэтому **просто открыть `index.html` двойным щелчком нельзя** —
> браузер заблокирует загрузку модулей по `file://`. Нужен любой локальный сервер,
> `npm start` поднимает свой (`tools/serve.mjs`, без зависимостей).

Полезные команды:

| Команда | Что делает |
| --- | --- |
| `npm run build` | одноразовая компиляция в `dist/` |
| `npm run watch` | пересборка при каждом сохранении |
| `npm start` | сервер на порту 5173 |
| `npm run typecheck` | проверка типов без вывода файлов |

## Что есть в игре

- **Полная школа изнутри**: 5 кабинетов, коридор, спортзал, актовый холл, столовая,
  библиотека, подсобка, лестница, двор за окнами — 72 × 44 м, ~88 000 треугольников.
- **Вступительная кат-сцена** из 12 сцен: двери входа, затемнение, класс, учительница у доски,
  её зовут в коридор, крик, темнота, тяжёлое дыхание, подъём с парты.
- **Учительница**: полноценная 3D-модель со **светящимися красными глазами** и дубинкой.
  Патрулирует школу, слышит бег, видит свет фонаря, преследует, бьёт, теряет след и ищет.
- **5 предметов** разбросаны по школе: гвоздодёр (спортзал), кусачки (столовая),
  ручка (библиотека), предохранитель (у лестницы), ключ (подсобка за кабинетом 105).
  Каждый предмет **виден в руке**, взятие — удержание `E` на 2.5 секунды с полосой прогресса.
- **Дверь выхода** вскрывается в 5 этапов: доски → решётка → замок → ручка → щиток.
- **Ночь**: через 22 секунды после начала свет гаснет, включается туман и темнота.
  **Фонарь лежит в кабинете 101** — том самом, где мы сидели за партой.
- **9 шкафчиков** для укрытия: внутри слышно шаги, учительница проходит мимо.
- **5 жизней**: после удара мы просыпаемся на полу класса, учительница отходит,
  даётся 3.5 секунды неуязвимости.
- **Финальная кат-сцена**: дверь открыта, мы убегаем во двор — «Игра пройдена!».
- **Меню**: игра, настройки (чувствительность, громкость, яркость, инверсия мыши),
  управление, «Об игре». Настройки сохраняются в браузере.
- **29 звуков**: 4 присланных вами + 25 синтезированных (прыжок, приземление, замок,
  удар, дубинка, шкафчик, сердцебиение, шёпот, звонок, мел, свет и т. д.).

## Параметры URL (отладка и скриншоты)

| Параметр | Что делает |
| --- | --- |
| `?autostart=1` | сразу игра, без меню и без захвата мыши |
| `?skipintro=1` | пропустить вступительную кат-сцену |
| `?night=1` | сразу ночь, фонарь в руке, учительница разбужена |
| `?warmup=10` | быстро прокрутить 10 секунд игрового времени |
| `?nosound=1` | запуск без загрузки звука |
| `?debug=1` | технический HUD: координаты, FPS, треугольники |
| `?spawn=gym` | точка старта (только вместе с `debug=1`) |

Пример: `http://127.0.0.1:5173/?autostart=1&skipintro=1&night=1&warmup=9`

## Исправления патча (09.09.2026)

По списку багов из теста заставки:

1. **Входные двери** открываются внутрь на своих петлях — обе створки остаются в кадре и не выворачиваются наружу.
2. **Доски-баррикада** на выходе появляются только после начала игры. Во вступлении школа ещё целая, как и должно быть.
3. **Учительница у доски** стоит спиной к классу, поднятой рукой ведёт мелом вдоль доски, в другой руке журнал. На доске постепенно появляются меловые штрихи и остаются до конца игры.
4. **Красные глаза** загораются только после крика. Когда она оборачивается на зов — это ещё обычная учительница, без дубины и без светящихся глаз.
5. **Дверь кабинета** — теперь отдельная створка на петлях. До ухода она закрыта, открывается ровно в тот момент, когда учительница берётся за ручку (со звуком), потом остаётся прикрытой.
6. **Конец заставки** больше не выдаёт ошибку: захват курсора обрабатывается аккуратно, а если браузер отказал — всплывает подсказка «Щёлкните по экрану, чтобы взять мышь».

Дополнительно нашлось и починилось:

- Квестовые предметы и фонарь не светятся во время заставки.
- Enter больше не проматывает заставку, когда игра на паузе.
- Камера за партой провожает учительницу взглядом до двери и плавно возвращается к доске — раньше весь уход проходил за краем кадра.
- Скорость письма мелом сбрасывается при новой игре: доска начинается чистой.

## Патч управления (09.09.2026)

Ходьба больше не зависит от захвата мыши. Раньше игровой цикл считал физику
только при активном pointer lock, а Chrome отказывает в захвате, когда запрос
пришёл не из жеста пользователя — ровно так было после заставки на 44 секунды.

- Шаги WASD, бег, прыжок, присед и взаимодействие работают всегда, пока нет паузы.
- Обзор мышью включается, как только курсор захвачен.
- Захват просим сразу в нажатии «Играть», чтобы он дожил до конца кат-сцены.
- Щелчок в любом месте экрана возвращает мышь в игру.
- Esc во время заставки больше не ставит игру на паузу.

Проверка: `node /data/qa_walk.mjs <url> deny skip` — автотест имитирует отказ
браузера в захвате мыши и меряет пройденное расстояние.

## Патч ходьбы после кат-сцены (09.09.2026)

Две причины, почему после заставки игрок не двигался:

1. Игровой цикл считал физику только при активном pointer lock, а Chrome
   отказывает в захвате мыши, если запрос пришёл не из жеста пользователя.
   Теперь шаги и взаимодействие работают всегда, обзор мышью — при захвате.
2. После заставки игрок вставал ровно в коллайдер парты. Шаг разрешён только
   в свободную клетку, а изнутри геометрии свободных направлений не было.
   Добавлены две страховки: поиск ближайшего свободного места при появлении
   и разрешённый шаг наружу, если игрок всё же оказался внутри объекта.

Проверка: `node /data/qa_probe.mjs <url> skip` и `... full` — автотест имитирует
отказ браузера в захвате мыши и меряет пройденные метры.
